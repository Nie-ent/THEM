# เอกสารออกแบบเกม (GDD) — THEM

Oct 31, 2026 · @Nie

## 1. ภาพรวมเกม

เว็บเกมแนว Survivors-like ผสม Tower Defense ผู้เล่นเป็น "มาสเตอร์" ที่ถูกส่งไปกอบกู้โลกที่กำลังล่มสลายทีละใบ สู้ฝูงศัตรูเป็นเวฟ สร้างฐานป้องกัน และชนะเมื่อล้มบอสของโลกนั้นได้

**ชื่อเกม:** THEM

**แพลตฟอร์ม:** เว็บเบราว์เซอร์ ทั้งคอมพิวเตอร์และมือถือ ออกแบบสถาปัตยกรรมให้ขยายไปแอปมือถือและรองรับผู้เล่นจำนวนมากได้ในอนาคต (ดูหัวข้อ 13)

**สไตล์ภาพ:** ในด่านเป็น 2D มุมมองจากด้านบน เน้นอ่านง่ายเมื่อศัตรูเต็มจอ ส่วนนอกด่าน (เมืองกลาง เมนู ภาพตัวละครและฮีโร่ หน้าสุ่มกาชา) เน้นความสวยงามระดับพรีเมียม เพราะเป็นส่วนที่ผู้เล่นเห็นก่อนตัดสินใจเล่นต่อและเติมเงิน

**เสาหลักการออกแบบ**

1. **อ่อนแอสู่แข็งแกร่ง** ต้นด่านต้องวิ่งหนีตาย ท้ายด่านกวาดศัตรูทั้งจอ
2. **วางแผนก่อนลงมือ** เกมโหดแบบฮาร์ดคอร์ ผ่านด้วยการฟาร์มเลเวลหรือกดมั่วไม่ได้ ต้องอ่านศัตรู จัดฐาน และเลือก build ให้ถูกกับแต่ละโลก
3. **Build สร้างสรรค์** Stat, Trait Tree, อาชีพ และฮีโร่ประกอบกันได้หลายแบบ ไม่มีทางเดียวที่ถูก
4. **ยุติธรรม** เงินซื้อความสะดวกและความสวยงาม ไม่ซื้อชัยชนะในโหมดแข่งขัน
5. **ค้นพบ** โลกมีความลับ เนื้อเรื่องลับ และอาชีพลับให้ตามหา

**แหล่งแรงบันดาลใจ** (ใช้เป็นแนวคิดและ ref เท่านั้น ชื่อ ตัวละคร ศัตรู และโลกออกแบบใหม่ทั้งหมด)

| ผลงาน | แนวคิดที่หยิบมา |
| --- | --- |
| Vampire Survivors | โจมตีอัตโนมัติ, ฝูงศัตรูมหาศาล, เลือกสกิลเมื่อเลเวลอัป |
| Versus (ONE) | ผู้กล้าถูกส่งไปหลายโลก แต่ละโลกมีภัยของตัวเอง, การหลอมรวมโลก |
| I Became the Tyrant of a Defense Game | ด่านป้องกันเป็นเวฟ, สร้างฐาน, บอสตามรอบเวฟ |
| Pick Me Up, Infinite Gacha | มาสเตอร์กับฮีโร่จากกาชา, ระดับดาว, ฮีโร่มีนิสัย, หอคอยไร้ที่สิ้นสุด, ฮีโร่ดาวต่ำไต่ขึ้นมา |

## 2. เนื้อเรื่องและโลก

ผู้เล่นคือผู้กล้าที่ อาร์ไคฟ์ ผู้เฝ้ามิติ เรียกมายังขอบกระดาษ แล้วส่งไปกอบกู้โลกที่ใกล้ล่มสลายทีละใบ แต่ละโลกมีบอสที่เป็นต้นเหตุของการล่มสลาย ล้มบอสได้คือโลกนั้นรอด

**หลักการเล่าเรื่อง**

- เล่าผ่านบทสนทนาสั้น ๆ ก่อนและหลังบอส ไม่ขัดจังหวะการต่อสู้
- เรื่องหลักเล่าในเมืองกลางผ่าน NPC เนื้อเรื่อง
- เนื้อเรื่องลับซ่อนอยู่กับ NPC ปริศนาและเงื่อนไขพิเศษ นำไปสู่อาชีพลับ

**โครงสร้างโลก** แต่ละโลกมีธีม ศัตรู บอส และกติกาพิเศษของตัวเอง

| # | โลก | ภัยคุกคาม | กติกาพิเศษ | บอส |
| --- | --- | --- | --- | --- |
| 1 | ทุ่งเลือดการ์รอธ | ชนเผ่าคนเถื่อนบุกเป็นฝูง | ศัตรูถือคบเพลิง เผาสิ่งปลูกสร้างไม้ได้ ต้องเลือกวัสดุสร้างฐาน | วาร์กุล ขุนศึกผู้ไม่เคยแพ้ |
| 2 | นครเงียบเนเครีย | ซอมบี้ระบาด | ศัตรูที่ล้มฟื้นขึ้นมาใหม่ถ้าไม่ทำลายศพด้วยไฟหรือดาเมจสุดท้ายแรงพอ | โมรา ราชินีรังเชื้อ |
| 3 | แดนวิปลาสคิมีรา | สิ่งมีชีวิตกลายพันธุ์ | ศัตรูปรับตัวต้านทานธาตุที่ผู้เล่นใช้บ่อยที่สุด บังคับให้สลับวิธีโจมตี | ปฐมพันธุ์ ต้นกำเนิดของทุกสายพันธุ์ |
| 4 | อาณาจักรนรกมัลกอร์ | ปีศาจจากประตูมิติ | ประตูนรกเปิดรอบแผนที่ ต้องออกไปปิดก่อนศัตรูทะลักไม่หยุด | อัซราเทล จอมปีศาจผู้ถูกล่ามโซ่ |
| 5 | ดาวที่ถูกยึดเวลเทรียส | ผู้รุกรานต่างดาว | ยานส่งศัตรูลงจากฟ้าในจุดสุ่ม รวมถึงกลางฐาน ศัตรูมีโล่พลังงาน | ผู้หว่านเมล็ด ยานแม่ที่ไม่มีผู้ควบคุม |

ลำดับโลกไล่ความซับซ้อนของกติกา โลกที่ 1 เป็นโลกสอนเล่น โลกที่ 5 ต้องใช้ทุกระบบร่วมกัน

### ตำนาน THEM: ผู้อยู่เหนือกฎ

ลาสบอสคือผู้สร้างที่อยู่เหนือกฎของทุกโลก เกมไม่เคยยืนยันว่ามันคืออะไร เปิดเผยแค่เศษเสี้ยวให้ผู้เล่นตีความเอง

**ชื่อเฉพาะ (ข้อเสนอ)**

| ชื่อ | คืออะไร |
| --- | --- |
| THEM | คำที่ทุกโลกใช้เรียกสิ่งที่ไม่มีใครเห็นตัว ไม่รู้ว่าเป็นหนึ่งเดียวหรือหลายตน |
| ผู้ประพันธ์ | ชื่อที่แท้จริงซึ่งถูกบอกใบ้ผ่านเศษบันทึก มองทุกโลกเป็นเรื่องเล่าที่ตนเขียน |
| อาร์ไคฟ์ | ผู้เฝ้ามิติที่เรียกผู้กล้ามา บรรณารักษ์ผู้เก็บบันทึกของทุกโลก |
| ขอบกระดาษ (The Margin) | ชื่อของเมืองกลาง พื้นที่ว่างระหว่างหน้าเรื่องที่ผู้ประพันธ์ไม่ได้เขียนถึง |
| เศษบันทึก | ไอเทมสะสมที่เล่าตำนานทีละชิ้น ดรอปจาก Raid ร้านค้าเร่ร่อน และเควสลับ |

**วิธีเล่าแบบลึกลับ**

- บอสทุกโลกพูดประโยคสุดท้ายที่ใบ้ว่าตนทำตามสิ่งที่ "ถูกเขียนไว้"
- ทุกโลกมีสัญลักษณ์เดียวกันซ่อนอยู่ เช่น รอยหมึกบนกำแพงหรือบนตัวบอส
- อาร์ไคฟ์ตอบคำถามเรื่อง THEM ไม่ตรงทุกครั้ง และบางคำตอบขัดกันเอง

**ทางตีความที่ตั้งใจเปิดไว้** (ไม่ยืนยันข้อใดเลย)

1. ผู้ประพันธ์กำลังลบเรื่องที่ล้มเหลว และผู้กล้าคือตัวละครที่ปฏิเสธจะถูกลบ
2. ผู้ประพันธ์กำลังหาผู้สืบทอด การกอบกู้โลกคือการสอบ
3. ภัยทั้ง 5 คือการต่อต้านของแต่ละโลกต่อผู้บุกรุกจากภายนอก และ THEM ในสายตาของโลกเหล่านั้นคือผู้กล้าเอง
4. อาร์ไคฟ์อาจเป็นผู้ประพันธ์ในอีกร่างหนึ่ง

**การต่อสู้กับลาสบอส (แผนอนาคต):** ไม่ปรากฏเป็นร่างชัดเจน ท่าโจมตีคือการเขียนกฎของด่านใหม่ระหว่างสู้ เช่น ลบป้อมออกจากแผนที่ สลับทิศการควบคุม หรือซ่อนหน้าจอข้อมูล ผู้เล่นต้องปรับตัวทันที

## 3. Core loop และโครงสร้างด่าน

1 โลก = 1 ด่าน 20 เวฟ สลับระหว่างช่วงเตรียมตัวกับช่วงต่อสู้ แพ้เมื่อผู้กล้าตายหรือแกนกลางโลก (Core) ถูกทำลาย ชนะเมื่อล้มบอสในเวฟ 20

&#91;embedded content: Core loop · เตรียมตัว → ต่อสู้ → เวฟถัดไป\]

**ช่วงเตรียมตัว** (20–30 วินาทีระหว่างเวฟ)

- ใช้ทรัพยากรที่เก็บได้สร้างหรืออัปเกรดกำแพง ป้อม และกับดักรอบ Core
- วางหรือย้ายฮีโร่ประจำการ

**ช่วงต่อสู้**

- ผู้เล่นบังคับแค่การเคลื่อนที่ ผู้กล้าโจมตีอัตโนมัติ
- ศัตรูดรอป EXP และทรัพยากร เลเวลอัปในด่านแล้วเลือกการ์ดสกิล 1 ใน 3
- ป้อมและฮีโร่ AI สู้เองตามตำแหน่งที่วางไว้

**ความตึงเครียดหลัก:** ออกไปล่าไกลฐานได้ EXP และทรัพยากรมากกว่า แต่ฐานเสี่ยงถูกตีแตก

**โครงสร้างเวฟ**

| เวฟ | สิ่งที่เจอ |
| --- | --- |
| 1–4, 6–9, 11–14, 16–19 | ศัตรูทั่วไป หนาแน่นขึ้นเรื่อย ๆ |
| 5, 10, 15 | มินิบอส ดรอปวัสดุหายาก |
| 20 | บอสของโลก หลายเฟส มีท่าไม้ตายที่ต้องเรียนรู้รูปแบบ |

### ความยาก: ต้องวางแผน ไม่ใช่ฟาร์มผ่าน

เกมให้ข้อมูลครบพอให้วางแผน แต่ลงโทษการเล่นแบบไม่คิด กลไกหลักมีดังนี้

| กลไก | ทำงานอย่างไร | บังคับให้ผู้เล่น |
| --- | --- | --- |
| ข่าวกรองก่อนเวฟ | ช่วงเตรียมตัวแสดงชนิดศัตรูและทิศที่จะบุกของเวฟถัดไป | จัดป้อมและฮีโร่ให้รับศัตรูชุดนั้น |
| ศัตรูแก้ทาง | ศัตรูหุ้มเกราะต้านกายภาพ, ศัตรูบินข้ามกำแพง, ผู้ก่อวินาศกรรมพุ่งใส่ป้อม, ผู้รักษา, ศัตรูแตกตัว | ไม่พึ่ง build ทางเดียว |
| ทรัพยากรจำกัด | ช่องวางป้อมมีจำกัด ป้อมมีค่าบำรุงทุกเวฟ | เลือกว่าจะลงทุนอะไรก่อน |
| จำกัดผลของการฟาร์ม | แต่ละโลกมีระดับพลังแนะนำ พลังที่เกินกว่านั้นให้ผลลดลงเรื่อย ๆ (เช่น เกินได้สูงสุด +10%) | ชนะด้วยการวางแผน ไม่ใช่ฟาร์มจนกดผ่าน |
| กลไกบอส | บอสมีหลายเฟส ส่งสัญญาณก่อนใช้ท่า บางท่าพุ่งเป้าที่ Core มีเวลาจำกัดก่อนบอสคลั่ง | อ่านท่า วางตำแหน่ง และสร้างดาเมจให้พอ |
| การ์ดสกิลมีราคา | การ์ดดี ๆ มีข้อเสียติดมา สุ่มการ์ดใหม่ได้จำกัดครั้ง | คิดก่อนเลือก |
| ระดับความยาก | ผ่านโลกแล้วเปิดระดับยากและฝันร้าย ซึ่งเพิ่มกติกาพิเศษ (เช่น ศัตรูเร็วขึ้น, ห้ามซ่อมป้อม) | ปรับแผนใหม่ทุกระดับ |

ด่านที่ยังไม่เคยผ่านไม่มีระบบเล่นอัตโนมัติหรือข้ามด่าน (ด่านที่ผ่านแล้วส่งทีมไปฟาร์มอัตโนมัติได้ ดูหัวข้อ 10) แพ้แล้วยังได้รางวัลบางส่วนตามเวฟที่ผ่าน เพื่อไม่ให้ความโหดกลายเป็นความเสียเวลา

## 4. ระบบเลเวลสองชั้นและค่าสถานะ

เลเวลแยกเป็นสองชั้น: In-stage Level ให้ความสนุกเฉพาะหน้าในด่าน ส่วน Global Level เป็นการเติบโตถาวรของบัญชี เพดานในเวอร์ชันแรกคือ Level 50

|  | In-stage Level | Global Level |
| --- | --- | --- |
| อายุ | รีเซ็ตทุกครั้งที่จบด่าน | ถาวร |
| ได้จาก | EXP จากศัตรูในด่าน | EXP บัญชีหลังจบด่าน, เควส, Raid |
| เลเวลอัปได้ | เลือกการ์ดสกิล 1 ใน 3 | Stat Point + Trait Point |
| บทบาท | การตัดสินใจเฉพาะหน้า | Build และเป้าหมายระยะยาว |

**ค่าสถานะหลัก** (แจกแต้มเองได้)

| Stat | ผลต่อ |
| --- | --- |
| พลังกาย | พลังโจมตีกายภาพ |
| ปัญญา | พลังเวท, ลดคูลดาวน์ |
| ความว่องไว | ความเร็ว, โอกาสคริติคอล |
| ความอึด | HP, เกราะ |
| การบัญชาการ | ความแรงของป้อม กับดัก และฮีโร่ AI |

**อุปกรณ์:** อาวุธแต่ละแบบเปลี่ยนสไตล์การเล่น (ดาบวงกว้าง, ธนูระยะไกล, เวทระเบิด) ชุดเกราะมีเซ็ตโบนัสและตีบวกได้

## 5. Trait Tree และการรีเซ็ต

Trait Tree มี 4 สาย ลงแต้มข้ามสายได้อิสระ เพื่อให้ผู้เล่นจัด build ได้สร้างสรรค์

| สาย | แนวทาง |
| --- | --- |
| ทัพหน้า | ระยะประชิด/แท็งก์ ยิ่งอยู่กลางฝูงศัตรูยิ่งแข็งแกร่ง |
| จอมเวท | เวทวงกว้าง ธาตุ และปฏิกิริยาระหว่างธาตุ |
| นักล่า | ระยะไกล คริติคอล การเคลื่อนที่ |
| ผู้บัญชาการ | เสริมป้อม กับดัก และฮีโร่ AI |

**กลไกที่ทำให้ build หลากหลาย**

- **Keystone มีข้อดีและข้อเสีย** เช่น
  - ปืนใหญ่กระจก: ดาเมจ +80% แต่ HP −50%
  - หมาป่าเดียวดาย: วางฮีโร่ไม่ได้ แต่ผู้กล้าได้ทุกค่าสถานะ +40%
  - เจ้าแห่งป้อมปราการ: ผู้กล้าโจมตีเองไม่ได้ แต่ป้อมและฮีโร่แรงขึ้นสองเท่า
- **โหนดผสม** ปลดล็อกเมื่อลงสองสายถึงเกณฑ์ เช่น ทัพหน้า + จอมเวท = อัศวินเวท (ฟันแล้วปล่อยธาตุ)
- **Trait ดัดแปลงการ์ดสกิลในด่าน** เช่น สกิลไฟกระดอนไปโดนศัตรูตัวถัดไป
- **ส่วนขยายเฉพาะอาชีพ** ปลดล็อกตามอาชีพที่เลือก (ดูหัวข้อ 6)

**การรีเซ็ต: ผลึกย้อนกาล** (ชื่อชั่วคราว)

ได้จาก: ซื้อด้วยเงินในเกม, เติมเงิน, กิจกรรม, เควสรายสัปดาห์, ของดรอปจาก Raid

- รีเซ็ตฟรีไม่จำกัดจนถึง Global Level 10 (ก่อนเลือกอาชีพ)
- รีเซ็ตฟรีทุกครั้งที่มีแพตช์ปรับสมดุล
- รีเซ็ตบางส่วน (เฉพาะสายเดียวหรือเฉพาะ Stat) ใช้ผลึกน้อยกว่า
- เงินเป็นทางลัด ไม่ใช่กำแพง ผู้เล่นฟรีต้องหาผลึกได้ด้วยการเล่น

## 6. ระบบอาชีพและอาชีพลับ

เลือกอาชีพแรกที่ Global Level 10 แตกสายที่ Level 35 และวางแผนอาชีพขั้นที่ 3 ไว้ที่ Level 60 เมื่อขยายเพดานเลเวลในอนาคต ส่วนอาชีพลับปลดล็อกผ่านเนื้อเรื่องลับเท่านั้น

| Global Level | ขั้น | ตัวเลือก |
| --- | --- | --- |
| 1–9 | ผู้กล้าฝึกหัด | ยังไม่มีอาชีพ ลองได้ทุกแนว |
| 10 | อาชีพขั้นที่ 1 | นักรบ / นักเวท / นักล่า / ผู้บัญชาการ |
| 35 | อาชีพขั้นที่ 2 | แตก 2 ทางต่ออาชีพ เช่น นักรบ → อัศวินโล่ หรือ คลั่งศึก |
| 60 (แผนอนาคต) | อาชีพขั้นที่ 3 | ขั้นสูงสุดของแต่ละสาย เปิดพร้อมขยายเพดานเลเวลเกิน 50 |
| เงื่อนไขพิเศษ | อาชีพลับ | ผ่านเนื้อเรื่องลับ |

**อาชีพให้อะไร**

- อาวุธเริ่มต้นและการ์ดสกิลเฉพาะอาชีพในกองสุ่มของด่าน
- ส่วนขยาย Trait Tree เฉพาะอาชีพ ส่วนสายหลักทั้ง 4 ยังลงข้ามสายได้
- เปลี่ยนอาชีพได้ด้วยไอเทมแบบเดียวกับผลึกย้อนกาลแต่หายากกว่า

**การค้นพบอาชีพลับ:** เบาะแสกระจายอยู่ในบทพูด NPC ปริศนา ไอเทมแปลกที่ดรอปใน Raid และเงื่อนไขซ่อน เช่น ผ่านโลกที่ 3 โดยไม่วางฮีโร่เลย

| อาชีพลับ (ตัวอย่าง) | กลไกเด่น |
| --- | --- |
| ผู้ทรยศมิติ | ใช้พลังของศัตรูที่ล้มได้กลับมาโจมตี |
| ผู้ผูกพันธะ | รวมร่างกับฮีโร่ประจำการชั่วคราว |
| สถาปนิกโลก | สร้างสิ่งปลูกสร้างกลางสนามรบระหว่างต่อสู้ |

**กติกา**

- ทุกคนที่ทำเควสสำเร็จได้อาชีพลับ คนแรกที่ค้นพบได้ฉายาเฉพาะตัว
- อาชีพลับต้อง "แปลก" ไม่ใช่ "แรงกว่า" เพื่อรักษาสมดุลโหมดแรงค์

## 7. ระบบฉายา

ฉายาได้จากความสำเร็จ ติดตั้งได้ 1 ฉายาหลักเพื่อรับโบนัสค่าสถานะ และยิ่งสะสมได้มากยิ่งได้โบนัสถาวรทั้งบัญชี

| ฉายา (ตัวอย่าง) | ได้จาก | โบนัส (ตัวอย่าง) |
| --- | --- | --- |
| ผู้ไร้รอยแผล | ล้มบอสโลกโดยไม่โดนโจมตี | ความว่องไว +5% |
| ผู้ไต่ฟ้า | ไต่หอคอยถึงชั้น 100 | ยังไม่กำหนด |
| ผู้รอดจากโลกหลอมรวม | ผ่าน Raid ระดับฝันร้าย | ยังไม่กำหนด |
| ฉายาซีซั่น | อันดับสูงในซีซั่นแรงค์ | ใช้ได้เฉพาะซีซั่นนั้น |
| ฉายาผู้ค้นพบ | ค้นพบอาชีพลับเป็นคนแรก | มีคนเดียวในเกม |

**กติกา**

- ฉายาหลักแสดงเหนือหัวให้ผู้เล่นอื่นเห็นในเมืองกลาง
- ฉายาที่ให้ค่าสถานะได้จากการเล่นเท่านั้น ฉายาจากการเติมเงินเป็นแบบตกแต่งอย่างเดียว
- ปิดโบนัสฉายาในโหมดแรงค์

## 8. ระดับดาว การอัปเกรด ฮีโร่ และกาชา

ฮีโร่จากกาชา (1★–5★) ไม่ได้ให้ผู้เล่นบังคับ แต่วางประจำการที่ฐานแล้วสู้เองด้วย AI ทำหน้าที่เหมือนป้อมที่มีชีวิต

**ตัวตนของฮีโร่**

- **นิสัย** กำหนดพฤติกรรม AI เช่น บ้าบิ่น (ไล่ศัตรูออกนอกฐาน), ระมัดระวัง (ไม่ออกจากจุด), ภักดี (คุ้มกันผู้กล้า)
- **ความผูกพัน** กับมาสเตอร์ เพิ่มได้ด้วยการคุยในค่ายทหารและรบด้วยกัน ยิ่งสูงยิ่งทำตามแผนดี
- **อัปดาว** ผ่านการตื่นพลัง/ทะลุขีดจำกัด ฮีโร่ 1★ ไต่ถึงระดับสูงสุดได้ แค่ใช้เวลานานกว่า

**ความตายของฮีโร่**

| โหมด | ผลเมื่อฮีโร่ล้ม |
| --- | --- |
| ปกติ / เนื้อเรื่อง / Raid | บาดเจ็บ พักฟื้นไม่กี่ชั่วโมง |
| หอคอยฮาร์ดคอร์ | ตายถาวร แลกกับรางวัลและเกียรติยศสูงสุด |

### ระดับดาวและการอัปเกรดตัวละคร

ทั้งผู้กล้าหลักและฮีโร่จากกาชามีระดับดาว 1★–5★ ดาวเพิ่มค่าสถานะพื้นฐาน ขยายเพดานเลเวลของตัวละคร และเปิดช่องความสามารถติดตัว

- **ผู้กล้าหลักเริ่มที่ 1★** ตามธีม "ฮีโร่ดาวต่ำไต่ขึ้นมา" อัปดาวด้วยตราผู้กล้าที่ได้จากบอสโลก หอคอย และ Raid เท่านั้น ซื้อด้วยเงินไม่ได้
- **ฮีโร่จากกาชา** เริ่มตามดาวที่สุ่มได้ อัปได้ด้วยผลึกดาว
- **หลัง 5★ คือการตื่นพลัง** ขั้น 1–3 สำหรับ End Game ใช้วัสดุจาก Raid ระดับฝันร้าย

| ไอเทม | ใช้ทำ | ได้จาก |
| --- | --- | --- |
| ตำราประสบการณ์ | เพิ่มเลเวลฮีโร่ | เควส, ด่านเนื้อเรื่อง, ฟาร์มอัตโนมัติ |
| ผลึกดาว | อัปดาวฮีโร่ | ฮีโร่ซ้ำจากกาชา, ร้านเหรียญ Raid, กิจกรรม |
| ตราผู้กล้า | อัปดาวผู้กล้าหลัก | บอสโลก, หอคอย, Raid |
| แก่นแท้แห่งโลก | ทะลุขีดจำกัด เปิดเพดานเลเวลตัวละคร | มินิบอสและบอส (แต่ละโลกดรอปแก่นแท้ของตัวเอง) |
| วัสดุตื่นพลัง | ตื่นพลังหลัง 5★ | Raid ระดับฝันร้าย |
| หินเสริมพลัง | ตีบวกอาวุธและเกราะ | ทุกโหมด |
| ใบกันแตก | กันระดับตีบวกลดเมื่อล้มเหลว | ฟาร์ม, ร้านค้าเร่ร่อน, กิจกรรม, เติมเงิน (จำกัดจำนวนต่อสัปดาห์) |

**การตีบวกอุปกรณ์:** การตีบวกไม่ใช่แค่ทำให้เก่งขึ้น แต่ผู้เล่นต้องชั่งว่าความเสี่ยงคุ้มไหม

| ระดับ | ผลเมื่อล้มเหลว |
| --- | --- |
| +1 ถึง +10 | สำเร็จแน่นอน |
| +11 ขึ้นไป | เสียหินเสริมพลังและทอง และมีโอกาสลดระดับตีบวก อุปกรณ์ไม่หายไป |

ใบกันแตกใช้ก่อนตีเพื่อกันการลดระดับ (ยังเสียวัสดุ) ส่วนที่ขายด้วยเงินจริงจำกัดจำนวนต่อสัปดาห์ เพื่อไม่ให้ใบกันแตกเฟ้อและระดับตีบวกสูงยังมีคุณค่า

**เพื่อความยุติธรรม:** ในโหมดแรงค์ เลเวลและระดับตีบวกถูกปรับให้เท่ากัน ส่วนดาวยังถูกจำกัดด้วยผลรวมดาวของทีม

**กติกากาชา**

- สุ่มฟรีและสุ่มเติมเงินใช้ตู้เดียวกัน อัตราเท่ากัน เงินซื้อแค่จำนวนครั้ง
- ระบบการันตี (Pity) เช่น ครบ 80 ครั้งได้ 5★ แน่นอน (ตัวเลขยังต้องปรับ)
- แสดงอัตราดรอปชัดเจนในหน้าสุ่ม
- โหมดแรงค์จำกัดผลรวมดาวของทีม เช่น ไม่เกิน 15★

## 9. เมืองกลาง NPC และเควส

เมืองกลางคือ "ขอบกระดาษ (The Margin)" ที่ผู้กล้าทุกคนพักก่อนออกเดินทาง และเป็นพื้นที่ที่ผู้เล่นออนไลน์เห็นกันและแชทกันได้

| พื้นที่ | ใช้ทำอะไร |
| --- | --- |
| หอกิลด์ | รับเควส, หาปาร์ตี้ Co-op และ Raid |
| ย่านการค้า | ร้านค้า, ช่างตีอาวุธ/เกราะ, ร้านแลกเหรียญ Raid |
| แท่นอัญเชิญ | สุ่มกาชาฮีโร่ |
| ค่ายทหาร | ฮีโร่อาศัยอยู่ คุยเพื่อเพิ่มความผูกพัน |
| ลานฝึก | ทดสอบ build กับหุ่นซ้อม, ใช้ผลึกย้อนกาล |
| ประตูมิติ | เข้าโหมดเนื้อเรื่อง หอคอย และ Raid |
| หอเกียรติยศ | กระดานแรงค์, รายชื่อผู้ครองฉายาหายาก |

**ประเภท NPC**

- **NPC บริการ** ร้านค้า ช่าง
- **NPC เนื้อเรื่อง** ให้เควสหลัก
- **NPC ปริศนา** ดูไม่สำคัญ แต่เป็นทางเข้าเนื้อเรื่องลับและอาชีพลับ บทพูดเปลี่ยนตามความคืบหน้าของผู้เล่น

**ประเภทเควส:** เนื้อเรื่อง, รายวัน, รายสัปดาห์, กิจกรรม, เควสลับ

### ร้านค้าเร่ร่อน

พ่อค้าลึกลับที่โผล่มาแบบสุ่ม ขายไอเทมที่สุ่มจากตารางของดรอปในเกม ผู้เล่นต้องตัดสินใจเร็วว่าจะซื้อหรือรอรอบหน้า

- **เวลาปรากฏ:** ในเมืองกลางวันละ 3 ครั้ง ครั้งละ 2 ชั่วโมงในเวลาสุ่ม และมีโอกาสน้อยที่จะโผล่ในช่วงเตรียมตัวระหว่างเวฟ (ตัวเลขยังต้องปรับ)
- **สินค้า:** สุ่ม 6 ชิ้นจากของดรอป เช่น วัสดุอัปเกรด, หินเสริมพลัง, ใบกันแตก, ผลึกย้อนกาล, แก่นแท้แห่งโลก, อุปกรณ์หายาก
- **การจ่าย:** ส่วนใหญ่ใช้ทอง บางชิ้นใช้คริสตัล แต่ละชิ้นจำกัดจำนวนซื้อ
- **รีเฟรชสินค้า:** ใช้คริสตัลได้จำกัดครั้งต่อการปรากฏ
- **ความลับ:** พ่อค้าเป็นหนึ่งใน NPC ปริศนา บางครั้งขายเบาะแสเนื้อเรื่องลับหรือไอเทมเปิดเควสอาชีพลับ

## 10. โหมดเกม

เกมมี 5 โหมด โหมดแข่งขันทุกโหมดปรับ Global Level ให้เท่ากันและปิดโบนัสฉายา เพื่อให้แรงค์วัดฝีมือและการจัด build ล้วน ๆ

| โหมด | ผู้เล่น | เป้าหมาย |
| --- | --- | --- |
| เนื้อเรื่อง | 1 คน | กอบกู้โลกทีละใบ |
| หอคอยไร้ที่สิ้นสุด | 1 คน (มีระดับฮาร์ดคอร์) | ไต่ให้สูงที่สุด เปิดหอคอยใหม่ทุกซีซั่น |
| Co-op | 2–4 คน | ไต่ชั้นพิเศษร่วมกัน ป้องกัน Core เดียวกัน |
| แข่งขัน | หลายคน | แข่งคะแนน และ PvP (รายละเอียดด้านล่าง) |
| Raid | 4 คน (มีโหมดเดี่ยวสุดโหด) | ล้มบอสหลอมรวม ฟาร์มของแรร์ End Game |

### โหมดแข่งขัน

มี 2 แบบ เปิดตามลำดับความยากในการพัฒนา: แข่งคะแนนก่อน แล้วจึงเปิด PvP เรียลไทม์

| แบบ | วิธีเล่น | ผู้เล่น | เปิดในเฟส |
| --- | --- | --- | --- |
| แข่งคะแนน | ทุกคนเล่นด่านเงื่อนไขและค่าสุ่มชุดเดียวกัน ไม่ต้องเล่นพร้อมกัน เทียบชั้นที่ไปถึง ความเร็ว และคะแนน | ไม่จำกัด | 4 |
| PvP ป้องกันฐาน | แต่ละฝ่ายป้องกัน Core ของตัวเองบนแผนที่แยกกัน ฆ่าศัตรูได้แต้มไว้ส่งเวฟเสริมหรือมินิบอสไปใส่ฐานคู่แข่ง Core ใครแตกก่อนแพ้ | 1v1, 2v2 | 5 |

PvP ไม่ต้องให้ผู้กล้าปะทะกันโดยตรง จึงรักษาความรู้สึกแบบ Survivors × Defense ไว้ และทนความหน่วงของเครือข่ายได้ดีกว่าการต่อสู้ตัวต่อตัว

### แรงค์

- แรงค์มาสเตอร์จัดจากคะแนนแบบ Elo ในโหมดแข่งขัน และชั้นสูงสุดในหอคอย
- แบ่งเป็นซีซั่น มีรางวัลและฉายาตอนจบซีซั่น
- ในโหมดแรงค์ ทุกคนใช้ Global Level เท่ากัน แต่ใช้การจัด Stat และ Trait Tree ของตัวเอง

### Raid: โลกหลอมรวม

ชิ้นส่วนของ 2–3 โลกถูกบีบรวมเป็นด่านเดียว ยากกว่าด่านปกติมาก และเป็นแหล่งของแรร์หลักของผู้เล่น End Game

- **เงื่อนไขเข้า:** ผ่านโลกที่เกี่ยวข้องในเนื้อเรื่องแล้ว และ Global Level ถึงเกณฑ์
- **กติกาซ้อน:** กติกาพิเศษของทุกโลกที่หลอมรวมทำงานพร้อมกัน เช่น เมืองซากศพ × แดนวิปลาส = ซอมบี้ที่ฟื้นคืนชีพและปรับตัวต้านธาตุได้ หรือ อาณาจักรนรก × ดาวที่ถูกยึด = ประตูนรกเปิดพร้อมยานทิ้งศัตรูกลางฐาน
- **ศัตรู:** ฝูงจากทุกโลกบุกพร้อมกัน มินิบอสคือบอสเก่าของแต่ละโลก บอสสุดท้ายเป็นบอสหลอมรวมที่มีท่าจากหลายโลก
- **บทบาทในทีม:** แท็งก์, ดาเมจ, ผู้บัญชาการคุมฐาน ฐานใช้ร่วมกัน แต่ละคนพาฮีโร่ของตัวเองมา
- **ระดับความยาก:** ปกติ / ยาก / ฝันร้าย
- **หมุนเวียน:** ชุดโลกที่หลอมรวมเปลี่ยนทุกสัปดาห์
- **ของดรอป:** ชุดเกราะเซ็ต Raid, อาวุธเอฟเฟกต์พิเศษ, วัสดุอัปดาวฮีโร่ขั้นสูง, ผลึกย้อนกาล, เบาะแสอาชีพลับ
- **กันดวงซวย:** จบทุกรอบได้เหรียญ Raid สะสมไว้แลกของที่ต้องการได้

## 12. ตัวเลขสมดุลเบื้องต้น

ตัวเลขชุดแรกคำนวณจากเป้าจังหวะการเล่น: ผู้เล่นที่ใช้พลังงานครบทุกวัน (ประมาณ 24 รอบ) ได้อาชีพแรกในวันที่ 2 อาชีพขั้นที่ 2 ราววันที่ 40 และถึง Level 50 ราววันที่ 90 ทุกค่าต้องปรับหลังทดลองเล่นจริง

### คะแนนด่านและเกรด

```latex
\text{คะแนน} = (\text{แต้มสังหาร} + \text{โบนัสบอส}) \times M_{\text{ความยาก}} \times M_{\text{ความเร็ว}} \times M_{\text{ความเสียหาย}}
```

| ตัวคูณ | สูตร | ช่วงค่า |
| --- | --- | --- |
| แต้มสังหาร | ศัตรูทั่วไป 1, ศัตรูชั้นยอด 5, มินิบอส 100 | ตามจำนวนที่ฆ่า |
| โบนัสบอส | ล้มบอสเวฟ 20 | 500 |
| ความยาก | ปกติ 1.0, ยาก 1.5, ฝันร้าย 2.5, กติกาเสริมฮาร์ดคอร์ +0.1 ต่ออัน | 1.0–3.0 |
| ความเร็ว | เวลามาตรฐานของด่าน ÷ เวลาที่ใช้จริง (เรียกเวฟก่อนเวลาได้) | 0.7–1.3 |
| ความเสียหาย | (0.7 + 0.3 × HP ที่เหลือของ Core) × (1.2 − 0.4 × สัดส่วนความเสียหายที่ผู้กล้าได้รับ) | 0.56–1.2 |

**ตัวอย่าง:** ทุ่งเลือดการ์รอธ ระดับปกติ ฆ่าศัตรูทั่วไป 1,600 ตัว ชั้นยอด 40 ตัว มินิบอส 3 ตัว และล้มบอส ได้ (1,600 + 200 + 300 + 500) × 1.0 × 1.15 × 1.05 ≈ 3,140 คะแนน

| เกรด | ความเร็ว × ความเสียหาย | รางวัลที่ได้ |
| --- | --- | --- |
| S | 1.40 ขึ้นไป | 120% |
| A | 1.15–1.39 | 100% |
| B | 0.90–1.14 | 80% |
| C | ต่ำกว่า 0.90 | 60% |

โหมดแข่งคะแนนใช้สูตรเดียวกันกับค่าสุ่มชุดเดียวกัน ฟาร์มอัตโนมัติได้รางวัลเท่าเกรด C เสมอ

### EXP และเลเวล

```latex
\text{EXP ที่ต้องใช้จาก Lv } L \text{ ไป } L+1 = 20 \times L^{2.2}
```

เล่นด่านที่ระดับพลังแนะนำได้เกรด A ได้ EXP บัญชี 50 + 20 × L ต่อรอบ

| เป้าหมาย | EXP ที่ต้องใช้ต่อเลเวล | รอบโดยประมาณ (สะสม) | ผู้เล่นทั่วไป | VIP (EXP ×1.5, พลังงาน ×1.5) |
| --- | --- | --- | --- | --- |
| Lv 10 อาชีพขั้นที่ 1 | 3,170 | 45 | วันที่ 2 | วันที่ 1 |
| Lv 35 อาชีพขั้นที่ 2 | 49,890 | 980 | วันที่ 41 | วันที่ 18 |
| Lv 50 เพดาน | 104,580 | 2,230 | วันที่ 93 | วันที่ 41 |

VIP ได้ทั้ง EXP ต่อรอบ ×1.5 และจำนวนรอบต่อวัน ×1.5 ผลรวมจึงเร็วกว่าผู้เล่นทั่วไปราว 2.25 เท่า ความได้เปรียบนี้ถูกจำกัดในด่านด้วยระดับพลังแนะนำ และไม่มีผลในโหมดแรงค์

- ตั้งระบบวัดผล (log, ตัวชี้วัดผู้เล่น) ตั้งแต่เฟสแรก

### Go สำหรับงาน concurrency ฝั่งหลังบ้าน

บริการหลังบ้านที่ต้องรับการเชื่อมต่อพร้อมกันจำนวนมากเขียนด้วย Go ส่วนการจำลองเกมฝั่งเซิร์ฟเวอร์ยังใช้ตรรกะเกมกลาง (TypeScript) ชุดเดียวกับฝั่งผู้เล่น เพื่อไม่ต้องดูแลกติกาเกมสองภาษา

| งาน | ภาษา | เหตุผล |
| --- | --- | --- |
| API Gateway, บัญชี, เศรษฐกิจและกาชา | Go | รับคำขอพร้อมกันจำนวนมาก ใช้หน่วยความจำต่ำ |
| Matchmaking, แชท, เมืองกลางออนไลน์ (WebSocket) | Go | goroutine รองรับการเชื่อมต่อค้างพร้อมกันได้ดี |
| จัดการห้อง Co-op / PvP / Raid | Go | เปิด–ปิดห้องและส่งข้อมูลระหว่างผู้เล่น |
| จำลองเกมในห้อง, ตรวจคะแนนแข่งขัน | TypeScript (Node worker) | ใช้ `packages/core` ชุดเดียวกับฝั่งผู้เล่น Go เรียกผ่าน gRPC |

บริการ Go อยู่ในโฟลเดอร์ `services/` ของ repo เดียวกัน เริ่มเขียนจริงในเฟส 4 ส่วนเฟส 1–3 เตรียมโครงไว้เท่านั้น

### หลายภาษา

รองรับไทยและอังกฤษตั้งแต่เวอร์ชันแรก และวางโครงให้เพิ่มภาษาอื่นได้โดยไม่แก้โค้ด

- ข้อความทุกชิ้นอ้างผ่านคีย์ ไม่เขียนข้อความลงในโค้ดตรง ๆ ไฟล์แปลแยกตามภาษา (`th.json`, `en.json`)
- ข้อมูลเกมใน `content` เก็บคีย์ของชื่อและคำอธิบาย ไม่เก็บข้อความ
- React และ Phaser ใช้ระบบแปลชุดเดียวกัน (i18next) สลับภาษาได้ระหว่างเล่น
- ตัดบรรทัดภาษาไทยด้วย `Intl.Segmenter` เพราะภาษาไทยไม่เว้นวรรคระหว่างคำ ตัวเลขและเวลาจัดรูปแบบด้วย `Intl`
- ฟอนต์โหลดตามภาษา ภาษาที่ใช้ตัวอักษรเยอะ (จีน ญี่ปุ่น เกาหลี) โหลดเฉพาะเมื่อเลือกภาษานั้น
- เทสต์อัตโนมัติล้มเมื่อมีคีย์ที่ยังไม่มีคำแปลในภาษาใดภาษาหนึ่ง

**จุดเสี่ยงทางเทคนิค**

- ศัตรูหลายร้อยตัวบนจอมือถือต้องรักษาความลื่นไหล
- Co-op เรียลไทม์ต้องจัดการความหน่วงและการโกง
- ผลกาชาและผลแรงค์ต้องคำนวณฝั่งเซิร์ฟเวอร์ ไม่ใช่ฝั่งผู้เล่น
